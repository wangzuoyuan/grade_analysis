# 双工作台考试管理

页面 `/homeroom/exams`、`/teaching/exams`，侧栏“考试管理”。按所选学年管理原生考试及只读关联来源。教学按本人所教班汇总整场考试，页面不沿用成绩页的单班选择，明确显示实际受影响班级。

- `GET /api/v1/{mode}/exams?academic_year_id=&class_id=&grade=` 返回 exams 与 scope。class_id 仅班主任；教学 grade 可选1/2/3。考试 key 由服务端目录生成，不以名称单独跨域删除。
- `POST /api/v1/{mode}/exams/delete-preview` `{academic_year_id?, class_id?, exam_key}` 返回单次token、有效期、考试名称/日期/年级/班级、学生数/成绩条数/均分行数/官方质量行数及将失效的导入预览数。仅共享来源返回404，不得修改对侧数据。
- `POST /api/v1/{mode}/exams/delete-confirm` `{token, confirm_name}` 必须完整匹配考试名称；确认在SQLite写锁下重验范围快照及全部目标行指纹。过期、作用域/关联/成员/数据漂移、重复确认409，错名422，失败整批回滚。
- 班主任删除本绑定行政班该场所有本域成绩（含已离班学生历史成绩）与该年级同场均分参照。教学新平台考试以TeachingExamScope.id定位该年级同科整场，旧格式以本域学年/学科/年级/考试名定位本人各教学班；同名其他年级/其他学年/其他域不删。未注明年级不推测。
- 教学质量表、class_snapshot及aggregates随所属考试一起删除，最新对比名册按剩余最近有效考试重建为新版本或空参照。普通名册、成员、身份、学年、作业、教师档案及另一工作台成绩保留。删除后仅共享成绩仍可见时，目录会显示“关联来源，只读”。
- 针对此场、同源范围的待确认导入整批失效；跨多场文件批次包含目标场时整批失效，重新预览才能导入。确认后的导入凭据/迁移归档保留；删除快照记录在本机数据库ImportBatch中（不返回前端、不写Git）。迁移映射被停用而非冒充仍有有效目标。
- 不触碰旧表Exam/SubjectScore/TotalScore/Upload。无需数据库迁移。页面暂不提供撤销，确认前完整列出影响；重新导入必须重新预览。
