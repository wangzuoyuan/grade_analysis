## 范围

仅 teaching，服务端校验配置学科，显式 academic_year_id、grade(1/2/3)、subject、exam_name、exam_date。学生文件可选按学号自动分班或指定教学班 ID，质量表可单独导入。所有标签大小写敏感，不根据样表固定班名或数量。

## 两阶段导入

- POST /api/v1/teaching/platform/imports/preview multipart: files、上述范围、teaching_class_id?、auto_assign?（与 teaching_class_id 互斥）、operation(initial|supplement)。仅写预览台账，返回 token、items、changes、conflicts、roster_changes、warnings；保留文件/表/行来源。
- 预览及确认的失败统一显示后端具体 `detail` 和全部冲突明细，逐项保留学号/姓名差异、字段/原因、原值/本次值、文件/行号等已返回信息；字符串与结构化 conflicts 均兼容，不因共用 `link_version_conflict` 而改写为“预览过期”，确认失败不展示原始 JSON。成功预览中的错误即使同时有 field 和 message，仍显示完整原因。此展示调整不解除身份冲突或改变任何确认/修订规则。
- 学生明细在前 10 行寻找同时含“学号、姓名”的表头，跳过标题行，从下一行读取；错误和字段来源保留原 Excel 行号。原始/原始分/原始分数、等级/等级分/等级分数、年级百分比/年级百分位分别映射同一字段；同字段重复列拒绝。“学籍”不映射学籍排名。现有年级格式约束、前导零、空白与 0 语义不变。
- 仅识别为质量分析结构后，按文件基本名（兼容路径分隔符、忽略空白）中的“教学班”/“行政班”确定类别，文件名优先于表头；两关键词同时出现须改名。无关键词且有“班级类型”列时回退行政班，否则提示补充文件名关键词再上传，不默认判为教学班。日期/副本等前后缀不限。成功质量预览 item 附可选 `class_kind: teaching|administrative`；请求及确认接口不变。
- auto_assign=true：多个教学班的学生明细合并成一个文件时，每个学生按学号解析身份后，须在其本人任教学科、年级匹配的教学班中**考试当日唯一**归属（成员有效期覆盖考试日期）；唯一命中归入该班，事实的 class_ref_id 按各自班级写入。未解析为已有学生（新学生/身份待确认）、不在任何班名册、同时属于多个班的学生逐个报错，整批零写入；自动分班不创建学生身份、不新增班成员，只为缺年级的归属班回填年级。
- POST /api/v1/teaching/platform/imports/confirm JSON: token、revise=false、accept_roster_changes=false、identity_confirmations?、identity_new_aliases?。复用身份候选规则（与旧模板导入同口径：本学年在册同号异名整批撞号拒绝；跨学年/未标学年历史同号——含异名——归候选，可显式接续或 `identity_new_aliases` 新建，声明须为预览候选清单内的学号否则 422；新建时历史学生记录不变）；锁定预览数据版本和成员/关联快照；任意冲突整批拒绝。新班参照变化必须显式确认。
- initial：新建事实；已有事实按文件实际非空字段合并，空白不清空；不同值须 revise。supplement：只能修改 grade_score(高二三)、xueji_rank/grade_percentile(高一)；原始分不同拒绝，无已有事实拒绝，不创建成员。
- 数值 0 有效，空白不同于 0，NaN/inf/非法数字拒绝；百分位与比例规范化为 0..1。重复自然键、同值跳过；同批互补合并；同字段异值冲突。令牌单次消费，事务失败回滚，版本漂移须重新预览。
- replace_roster=true 是显式分班变化：仅替换本批质量表所提供类别，预览列出移出/纳入并确认；默认补充保留。已存在考试的名单修订同时要求 revise。修订旧考试不更新由更新考试建立的最新参照；旧快照保留在确认回执。

## 读取

- GET /api/v1/teaching/platform/exams?academic_year_id=&grade=&subject=：包含仅有质量表的考试。
- GET /api/v1/teaching/platform/exams/{id}/compare：classes、metadata、overall(raw/grade)、warnings。班级快照与当前参照分离；official / estimated 明确标识；同来源同口径排名；缺值 null。
- GET /api/v1/teaching/platform/exams/{id}/students?teaching_class_id=：仅本人教学域合法成员成绩；rank 为当前所选管理班范围名次，xueji_rank 为来源学籍排名，grade_percentile 为来源百分位，grade_label 仅由已导入等级分精确映射。归并考试可跨多日：明细按事件/考试 id 匹配，不钉死单一 exam_date（每条事实保留自己的日期）；考试当日成员有效期逐条按**该事实自己的 exam_date** 判定，日期不在名册/共享范围的学生绝不出现。
- 质量表中的小计/合计作为 aggregate 单独保留及覆盖说明，不作班级。高一四个分数段不要求人数合计等于实考；高二三保留等级人数合计检查。比率分母由学校定义，不用人数÷实考（或应考）反算校验、告警或覆盖；比率、均分、标准差等官方指标按表值读取，空白不补算，百分比仍规范化为 0..1。其他基本数字校验及对比页既有总体/均差分析保持原有行为。
- 合计行 A:B 合并时字段左移一列，按合并区域定位；覆盖人数核对成功的汇总才可作为总体依据。同覆盖汇总出现不同均分时总体/均差不可用。教学班分组没有互斥证据和匹配汇总时不直接加权。
- 总体：匹配同范围官方合计优先；否则仅完整、不重叠同类班按实考人数加权，等级均分需等级人数覆盖完整。混合教学/行政班覆盖不明时不可合并。均差使用同 source/basis/coverage 的总体。

## UI

/upload 教学侧统一使用教学平台单科入口，不再提供旧模板切换或相关错误引导；班主任上传、共用旧解析器与后端接口仍保留。质量表预览显示教学班/行政班类别、纳入数与排除行原因，无法确定类别时提示修改文件名，不提供类型选择框。/compare 官方质量原表（2026-10-22 起合并单卡 + 各班平均分柱状图 + 各班等级人数堆叠条）使用上述新布局；旧样本入口已于 2026-10-22 移除。学年/年级/学科/考试显式，成绩与汇总单独加载；学生表无数据不阻断官方对比。快速切换丢弃迟到响应，变更输入使预览失效。学生明细分班默认「按学号自动分到各教学班」（多班合用一个文件），可改为指定教学班或仅质量表。

上传页提供与当前年级对应的空白 `.xlsx` 模板下载：高一学生明细及质量分析，高二/高三学生明细、教学班质量分析、行政班质量分析。补录使用同一学生明细模板。班主任入口仍提供高一、高二/高三的全科明细与班级均分模板。模板位于 `/templates/scores/v1/`，只含原有解析器要求的单工作表表头与空白填写区，不含学生、班级名单、考试或学年数据；学号列按文本、比率列按百分比格式保存，下载不创建预览或业务记录。

下载通过浏览器 blob 保持带年级、质量表类别的中文文件名，避免宿主的 Content-Disposition 覆盖名称并影响识别。教学侧历史模板静态资源继续保留，但页面不再提供旧入口；请求失败展示可重试提示。
