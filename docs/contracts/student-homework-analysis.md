# 逐人作业与成绩分析（2026-10-17）

`GET /api/v1/{homeroom|teaching}/diagnosis/homework-students`

参数：沿用工作台 `academic_year_id`、`class_id` / `teaching_class_id`；班主任 `subject` 指定同科成绩与作业，教学恒钉任教学科；可选 `grade=1|2|3`、`person_id`、`end_exam_name`、`window_days=14|30`、教学 `homework_type`。越界人/考试404，考试同名跨范围歧义422。无学科班主任请求422。

返回 `students` 每人含基本身份、逐场 `timeline`、`correlations`（提交率对成绩水平、提交率对进步、负面评价率对成绩水平）、`latest_change`、`advice`、`caveats`。所有数值有相应口径、分子分母、缺失原因；没有全班系数或总分分层。

- 当前成员清单遵循后端范围。历史事实只读统一 readable_facts，并逐班核验考试时点成员；作业使用当前授权的事件时点共享门和确认快照。统计豁免只用于预警等聚合，本个人分析保留。不自动关联同名身份。
- 高一 `grade_percentile` 归一化后原值是“前百分之几”（小为好）；计算成绩值 `100*(1-p)`（大为好）。高二/三只取 `grade_score`。原始分仅供明细参考。缺考即使残留指标也不参与；真实0分/0百分位保留。未知年级、跨年级、缺指标不得用原始分/班内排名/学校人数补造。
- 一个观察是一场考试。精确日期窗口 `[max(考试日-N, 上一场同科考试日+1),考试日)`；上一场依据当前学生可读的同科考试时间线（包括缺考场）。同日多场保留明细但排除关联及进步比较。月份/缺日期不伪造考前日期。截止考试含该场，未来场不参与。
- 有应交快照才可默认已交。请假、忘带、出勤行不计提交率分子分母；考勤批次整批排除。取消批次排除。负面评价只在有效已交作业中计数，负面率分母为有评价作业数；覆盖率为有评价作业数 / 已交数；其他评价不当正面，无评价不当优良。评价关联要求每窗至少3份有文字评价的作业且覆盖率至少50%。分母不明批次在个人窗口内超过已知有效份数时，该窗也不参与系数。
- 系数配对每窗至少3份有效作业；6场才给探索系数，少于10场提示样本少（均为产品门槛，不是统计显著性界限）。提交率零方差/成绩零方差返回null及原因，集中或并列提示辨别力受限。Spearman平均秩，Pearson仅辅助；删一场的rho范围为敏感性检查，不是置信区间。进步仅比较时间线上相邻且同口径的两场，不跨缺考/缺失/未知场补连。负面评价率高对应成绩低时相关为负，不倒置含义。
- 只描述该学生在所选条件下的共变；时间趋势、考试内容、辅导与记录偏差仍可能影响。没有p值、因果、提分预测、能力标签或全班系数推断。

方法参考：[NIST并列平均秩Spearman](https://itl.nist.gov/div898/software/dataplot/refman1/auxillar/rankcorr.htm)、[Bland与Altman关于个体内与个体间关联的区别](https://www.bmj.com/content/308/6933/896)。
