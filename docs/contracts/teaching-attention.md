# 教学首页优先跟进（2026-10-17）

仅教学首页重做两张旧名单；班主任页面/主三门诊断保持现有口径。

- GET /api/v1/teaching/diagnosis/attention：后端解析 academic_year_id、teaching_class_id，按当前成员person_id去重。返回students、counts、gaps、settings、明确30天观察窗口。全部页签只列active，待复查包含未到期跟进。无理由不入选。
- 成绩目录与取值复用student_homework的统一可读事实和考试时点成员门。高一年级百分位转换为向上为好的值，高二三只取等级分；不以原始分/班内排名代替。精确日、同学科/学年/年级，两场可明显下滑，最近三场连续两次下降且累计达到门槛可持续下滑；缺考/缺指标/未知年级/同日多场不补连。只有一场单列数据积累状态。
- 默认明显下降5个百分点/3等级分是可调整产品门槛，非统计显著性。PUT /settings持久化于HomeworkSetting的教师/学年/学科键。高一前百分比目标与高二、高三等级分目标均默认null，连续三场低于明确目标才提示持续支持。
- 作业复用homework_warnings，近30自然日（历史学年夹于学年边界），连续缺交>=2天、负面>=2条及忘带/出勤>=3次各用现有口径；统计豁免只抑制作业理由，不抑制成绩提醒。无可靠应交快照不算提交率。最新记录不足不推断全交。
- 到期复查置顶，然后成绩与作业同时异常、持续下滑、明显下滑或作业异常、持续支持。人数按学生去重，理由并列；不把不同年级的原始分比较成优先级。
- POST /{person_id}/follow-ups：明确措施/复查日/evidence_key；写锁内重新核对范围和当前证据，不允许重复未关闭跟进。WsStudentNote保存本域学科、问题、措施、review_date和baseline_value证据快照，不新增表。
- 相同已处理证据退出active进入待复查；新的考试/异常或程度增加可再次提醒。同生改善后原待复查仍保留。POST /follow-ups/{note_id}/finish要求复查观察，关闭事项但保留最初证据与历史；关闭的相同证据不立即重复提醒。旧本域手工待办纳入，不能跨学科/学年/班级或读取班主任私密档案。
- 前端6人默认折叠、全部可展开；查看依据/基线与当前对照/关注规则/加入跟进/记录复查，姓名直达个人档案。切换范围卸载卡片并丢弃迟到响应，保存失败可重试。
- 本服务不输出成功判定、因果推断或提分预测；原有个人相关分析不参与提醒门槛。
