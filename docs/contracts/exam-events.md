# 统一考试标识与确认规则

## 身份与范围

`workspace_exam_event.id` 是稳定的考试归属，名称仅作标签。学年和明确年级参与匹配；成绩、单科官方范围、均分各自保留 `exam_event_id`。归并只设置 `merged_into_id`，原事实、原事件与字段来源不变。解析根事件后去重，不放大个人考试次数或成绩分母。

本应用首版为老师本人使用，考试名称、日期、年级这些事件元数据可跨工作台用于识别；它们不授予成绩读取权限。两域事实仍通过 `readable_facts`、显式班级关联、已确认身份映射、任教学科、历史授权与考试时点成员交集读取。教学侧不得读取其他班、其他科或总分。确认台账不复制对侧全科成绩。

数据库表达式唯一索引以非空事件标识为考试键，旧无事件行退回原名称约束。这样同名异日考试能分开保存，直接 SQL 与 ORM 行为一致。

## 新导入

- 预览仅写短期 `ImportBatch`，不创建事件或成绩。返回 `exam_resolution`：候选 ID、名称、年级、日期、来源、默认选择和是否必须选择。
- 学年、年级、名称、日期完整且唯一匹配时自动选中，显示“将归入已有考试”；普通导入确认后生效。无同名候选且元数据完整时默认新建。
- 同名异日、多候选、缺日期、缺年级、批内同名异日必须明确选已有考试或 `new`。多日事件由老师明确选择，原学科日期不改写。
- 旧模板确认传 `exam_choices: {filename: event_id | "new"}`；教学平台确认传 `exam_choice`。候选漂移、范围变化、已消费或过期令牌整批拒绝；SQLite 写锁覆盖重验和写入，失败回滚。
- 同事件内已有本域成绩仍按逐字段差异处理，禁止静默覆盖。缺考保持 NULL。平台补录不改原始分，空白不清除已有指标。

## 历史考试与指标补齐

- 0020 迁移按原来源分别建立事件，不自动合并历史跨域同名记录。迁移事务保留所有旧列值、成员和外键；外键图检查通过后提交版本标记。
- 两域考试管理 `/exams/merge-preview` 接收 `source_event_id` 和 `target_event_id`，列出当前可读来源、班级、字段差异；`/merge-confirm` 要求一次性 token、目标完整名称、差异保留确认。锁内重验全来源指纹；不同年级、未知年级、越界或已归并来源拒绝。
- 归并不覆盖原始分、等级分、百分位。两个工作台保留各自值并提示差异。当前可读事实按本域优先、同域最新行展示，原行仍可核对。
- `/metric-fill-preview` 接收本域 `fact_id`；只在已确认同人、同事件、同学科且两边原始分相同并且非缺考时，列出可填补的空白等级分或百分位。`/metric-fill-confirm` 确认后只填空值，保留源事实 ID、来源域和确认时间，已存在不同值不覆盖。补齐来自逐条共享门内的来源。
- 删除按根事件聚合当前域的来源，依旧预览及完整名称确认；只删本域数据，另一工作台和只读投影保留。已归并多份官方范围都纳入本域删除，历史参照回退到未删除考试。

## 读取

`/shared/exams` 返回 `exam_name`、`exam_key`、日期和统计；选择器传稳定 `exam_key`（`event:<id>`），界面显示名称和日期。旧名称调用保留兼容，但存在多场同名根事件时明确拒绝。成绩分析、画像、诊断、个人作业时间线和管理目录均解析同一根事件；原学科日期冲突保留缺失原因，不猜测先后顺序。原始旧接口的标签字段继续显示可读名称。
