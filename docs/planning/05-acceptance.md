# 验收标准

这是未来实现必须通过的验收，不是本次已运行的测试结果。

## 核心合成样本

设置行政班 H6（本人班主任班）、教学班 T6（同班）、T8（只任教），任教学科物理；另有旧学年 H6/T6、同名学生甲乙、跨届相同裸学号、无成绩名单成员。
H6 有语数英/物理和总分；T8 只有物理数据；H6/T6 有明确关联，T8 没有关联。每个样本使用虚构姓名和学号。

| 编号 | 场景 | 必须成立 |
|---|---|---|
| S01 | 未配置/空成员/非法班 ID | 不回退全校；返回可操作空态或确定的错误 |
| S02 | H6 与 T6 关联 | 只共享交集学生的物理成绩/作业/名册；总分和语文仅 H 可见 |
| S03 | T8 学生与 H6 同名/同学号 | 不自动合并、不进入 H 的检索、统计、导出或 AI |
| S04 | 直接 API、篡改班 ID、任意 alias | 无法绕过域和关联约束；非法请求零写入 |
| S05 | 同场考试同时含 T6/T8 | H 只见允许的关联班数据；考试映射不放开 T8 |
| S06 | 取消关联/换届/过期 | 跨域共享立即停止，清缓存；域内原数据保存 |
| S07 | 两标签页分别打开 H/T，快速切换 | 各自保持范围，迟到响应不覆盖；草稿不丢，聊天不串 |
| S08 | 关联学生改号/同名身份确认 | 映射明确，历史接续；教学其他学生不受影响 |
| E01 | 相同输入在 H 全科和 T 单科分析 | 分数与来源一致；T 不返回其他科/总分字段 |
| E02 | 缺考、0 分、仅百分位残留、同分 | null 与 0 区分；无真实分数不进趋势；同分名次一致 |
| E03 | 高一→高二趋势/选考等级分 | 不跨学年直接比九科总分；高二三选考按等级分规则；标注口径 |
| E04 | 班均估算、年级排名、小样本 | 官方/估算明确；不能拿班内样本计算后冒充年级排名 |
| E05 | 重复上传、修订、失败回滚 | 幂等，冲突可见；解析或成员同步失败不残留半个考试 |
| I01 | 名册创建、替换学号、撤销导入 | 成绩/作业/档案/教学成员/映射全部一致；后续编辑冲突不被回滚覆盖 |
| I02 | 历史班成员/当前成员/无成绩成员 | 历史不被当前名册重写；无成绩学生仍可管理和录作业 |
| H01 | 全交+个人缺交/请假，两种行顺序 | 结果一致；同人同批次唯一；矛盾个人状态拒绝 |
| H02 | 重试同批次、同日两份作业 | 重试不增，两份不合并；预警按事件顺序 |
| H03 | 仅缺交历史、名单改变、未知状态 | 不推断已交；分母未知不算提交率；未知不冒充连续缺交 |
| H04 | 关联班从任一侧修改物理作业 | 双方同一规范事实；其他科/其他教学班不受影响；并发 revision 冲突明确 |
| H05 | 换号后按人聚合 | 历史跟人，去重；身份展开不突破域、学科和关联时期 |
| H06 | 学期自动/手工/重复编辑 | 可回自动，保留手工日期；重复返回 4xx，不发生 500 |
| N01 | H 家访谈话 + T 教学观察 | 默认各域独立；关联班不能顺带开放私密档案 |
| A01 | 页面、API、AI、MCP 同一查询 | 结构化结果和范围一致；只读工具不能写入或扩大范围 |
| A02 | 聊天流中切换工作台/撤销关联 | 旧结果不能继续作为新范围上下文；后续调用重新校验 |
| M01 | 双库迁移两次/中断重试 | 来源行对账完整；重复不增，失败可恢复 |
| M02 | 冲突原成绩与撤销 JSON | 不静默覆盖；历史操作引用正确或只读标记明确 |
| D01 | 候选部署/备份恢复/回退 | 新旧数据目录分离；恢复可查询；上线新增数据有回退方案 |
| U01 | 390/768/1280/1440 + 打印 | 教学版风格一致，切换器和宽表可用，无裁切和遮挡 |

## 命令与环境

P0 在独立虚拟环境使用 `backend/pyproject.toml` 安装依赖（现有两个仓库没有 requirements.txt）。
在导入 app 前显式设置 `EXAM_TRACKER_DIR` 和 `EXAM_TRACKER_BACKUP_DIR` 到临时目录，不使用个人默认目录。

后端现有命令：`python -m pytest tests/ -q`（在 backend）。测试依赖按现有 CI 安装 `pytest httpx`。
前端现有命令：`npm ci`、`npx tsc --noEmit`、`npm run test:ui`、`npm run build`（在 frontend）。
H 的 test:ui 含 Vitest 交互套件，T 的 test:ui 主要是 Node 契约测试；迁入 T 前端后须补足交互验证，不能只检查源码字符串。
现有 package.json 未提供通用 `npm test` / `npm run lint`，不要虚构命令；如要增加，单独交付配置。
集成阶段执行完整后端、前端类型/交互/构建和浏览器核心路径；部署阶段执行 `docker compose ... config --quiet` 与真实健康/恢复验证。

报告记录提交 SHA、环境、实际命令、通过/失败/跳过数量及日志位置。原版已有失败单独登记，不能降低新增验收条件或删除失败测试来过关。
